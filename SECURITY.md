# Security Policy

## Supported Versions

mongo4s is pre-1.0. Only the latest published release is supported; there is no back-porting of
fixes to older versions at this stage.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, use [GitHub Security Advisories](https://github.com/mongo4s/mongo4s/security/advisories/new)
to report privately, or email **shadowsmind.dev@gmail.com** with details and, if possible, a minimal
reproduction.

You should expect an acknowledgement within a few days. Once a fix is available, we'll coordinate on
disclosure timing and credit before making anything public.
